# VoiceVerse 🎙️

VoiceVerse is an innovative web application designed to provide seamless interaction with AI-generated voices. It enables users to convert text to speech, customize voices, and explore the possibilities of voice technology.

## Features 🚀

- **Text-to-Speech (TTS):** Convert any text input into natural, AI-generated speech.
- **Voice Customization:** Personalize the voice tone, pitch, and speed to suit your needs.
- **Multi-Language Support:** Engage with voices in various languages and accents.
- **User-Friendly Interface:** Intuitive design for effortless interaction.

## Getting Started

### Prerequisites

Before you begin, ensure you have the following installed:

- [Node.js](https://nodejs.org/)
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Fatmaamr61/VoiceVerse.git
   cd VoiceVerse
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm start
   ```

4. Open the app in your browser at `http://localhost:3000`.

## Usage

1. Enter text into the input box.
2. Select desired voice settings (tone, pitch, language).
3. Click the **Convert** button to hear the generated voice.
